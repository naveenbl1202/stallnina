# Stall Nina – Webbplats

En webbplats för stall Nina, byggd som en snabb och enkel statisk sajt med ett innehållshanteringssystem (CMS) så att innehållet kan uppdateras utan att koda.

> Ett webbprojekt som visar mitt arbete med frontend och statiska webbplatser. Byggt som en del av min utbildning.

## ✨ Funktioner
- Snabb, statisk webbplats genererad med Eleventy (11ty)
- Innehåll som kan redigeras via Netlify CMS – inget kodande krävs för uppdateringar
- Responsiv design för mobil och desktop

## 🛠️ Tech stack
- **Statisk sidgenerator:** Eleventy (11ty)
- **CMS:** Netlify CMS
- **Frontend:** HTML, CSS, JavaScript
- **Bygg & pakethantering:** Node.js / npm
